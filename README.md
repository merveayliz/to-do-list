## 📖 Proje Hakkında / About
**TR:** To-Do List, kullanıcıların günlük işlerini, planlarını ve Hedeflerini düzenli bir şekilde takip edebilmesi için geliştirilmiş interaktif bir web uygulamasıdır. Temiz arayüzü ve akıcı kullanıcı deneyimi ile üretkenliği artırmayı hedefler.

**EN:** To-Do List is an interactive web application developed for users to track their daily tasks, plans, and goals in an organized manner. It aims to boost productivity with a clean interface and smooth user experience.

---

## ✨ Özellikler / Key Features
- ➕ **Görev Ekleme / Add Tasks:** Hızlı ve kolay bir şekilde yeni görevler oluşturma. / Create new tasks quickly and easily.
- ✔️ **Görev Tamamlama / Task Completion:** Yapılan görevlerin üstünü çizme veya tamamlandı olarak işaretleme. / Cross out or mark tasks as completed.
- 🗑️ **Görev Silme / Delete Tasks:** Artık ihtiyaç duyulmayan görevleri listeden kaldırma. / Remove tasks that are no longer needed from the list.
- 📱 **Mobil Uyumlu / Responsive Design:** Tüm cihazlarda sorunsuz çalışan esnek arayüz. / Flexible interface that works seamlessly on all devices.
- 🎨 **Modern UI:** Göz yormayan, şık ve minimalist tasarım anlayışı. / Eye-friendly, stylish, and minimalist design approach.

---

## 🛠️ Kullanılan Teknolojiler / Tech Stack
* **HTML5:** Sayfa yapısı ve semantik elementler / Page structure and semantic elements
* **CSS3:** Stil yönetimi, modern layout ve geçişler / Styling, modern layout, and transitions
* **JavaScript (DOM Manipulation):** Görev ekleme, silme ve dinamik arayüz yönetimi / Task creation, deletion, and dynamic UI management
